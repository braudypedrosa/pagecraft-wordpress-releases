Pagecraft WordPress 0.2.7

Updates screen

- Pagecraft updates now read "Compatible with WordPress" on every version of the WordPress branch they were tested on, instead of "Not tested" on point releases.
- "View version details" opens a window with the version, the WordPress and PHP it needs, and a link to its release notes.

Site Settings

- The settings appear at once. They used to fade in over about three seconds, looking greyed out.
- "Loading Site Settings…" shows until they appear.
- "Site Settings saved" and save failures now appear as toasts, like the other Pagecraft screens. A failed save says so in plain words.

Pagecraft Cloud

- Before connecting, the Cloud screen lists the three steps that follow: sign in, choose a project, review and confirm.
- An account with no projects gets a short note with "Check again" and "Open Pagecraft".
- Every Cloud screen now uses the same frame; the old step bar is gone.

Release validation requires hosted WordPress desktop/mobile acceptance for the packaged artifacts; local fixture and CI testing alone do not certify production hosting.
