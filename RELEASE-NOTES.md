Pagecraft WordPress 0.2.6

Outdated pages are listed on the Overview

- When pages or templates need updating, the Overview lists "Site output" under "Needs attention" with the count. When everything is current it reads "Up to date".
- It uses the same check as the Status screen, so the two always agree.

Settings is now Status

- The screen that checks site output is called "Status", because nothing on it can be changed. Its address is the same.
- Status lists the Theme and Importer versions beside the Builder version.
- Each row is one plain sentence; labels that read like options are gone.
- The Overview says "Pagecraft Cloud" and shows "Connected" as plain text.

Cloud: the last two steps match the picker

- Choosing the pages for a one-page replacement, and the review before replacing, now use the same frame as the project list. The step bar and side panel are gone from both.
- On the review, the confirmation checkbox and the "Replace" button sit on one line.

Fixes

- The last item in the Pagecraft bar is no longer pushed out of view at narrow desktop widths.
- On tablets, the Cloud steps use the same side spacing as the tables around them.

Release validation requires hosted WordPress desktop/mobile acceptance for the packaged artifacts; local fixture and CI testing alone do not certify production hosting.
