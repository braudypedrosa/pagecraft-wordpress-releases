# Pagecraft for WordPress releases

Published releases of the Pagecraft Importer, Pagecraft Builder and Pagecraft theme.

WordPress sites running Pagecraft read `stable.json` from this repository to find out about
new versions, and download the packages from the tagged `packages/` folder. Every package is
checked against a signed record before WordPress installs it.

This repository is written by an automated release process. Please do not open pull requests here.

- Site: https://itspagecraft.com/
- Each release and its notes: see [Releases](../../releases).
